¿De qué trata este sitio?

Aquí encontrarás información sobre algunos lenguajes y herramientas que utilizamos en la carrera de Software.

La idea es conocer para qué sirve cada uno y tener una guía básica para comenzar a programar.

Qué necesitas para empezar

  • Un editor de código, como Visual Studio Code.
  • Un lenguaje de programación, como Python o JavaScript.
  • Git para guardar los cambios de tus proyectos.
  • Una cuenta en GitHub para publicar tus páginas.
  • Una base de datos, como SQL Server.

Cómo usar la guía

Entra al catálogo para conocer los seis lenguajes de programación y las seis herramientas seleccionadas.

Cada tarjeta contiene una pequeña descripción y un enlace para consultar más información.

También puedes visitar la página de recursos para encontrar sitios donde practicar.

Consejos para aprender

  • Practica un poco todos los días.
  • Comienza aprendiendo un lenguaje.
  • Realiza pequeños proyectos.
  • Guarda tus trabajos en GitHub.

Sitios para practicar

Estos sitios ofrecen recursos y ejercicios para mejorar tus conocimientos de programación.

  • freeCodeCamp: cursos gratuitos y ejercicios de programación.
  • MDN Web Docs: documentación de HTML, CSS y JavaScript.
  • W3Schools: ejemplos para practicar diferentes lenguajes.
  • Microsoft Learn: cursos y recursos de tecnología.
  • Pro Git: libro gratuito para aprender a utilizar Git.
